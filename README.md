# Web UI Exam Practice

## Overview

A small HTML-based interface exercise with `index.html` and `finish.html` pages.

## Mission

Practise the structure and presentation of web user interfaces while applying the HTML and CSS skills covered in class.

## Goals

- Build clear page structure with HTML.
- Create consistent navigation and page layouts.
- Practise form and interface presentation where required by the exercise.
- Keep the pages usable on different screen sizes.
- Review the final result against the assessment requirements.

## Project structure

- `index.html` — main page
- `finish.html` — completion/final page

## Getting started

Open `index.html` in a modern browser. Add any required stylesheet or assets as the exercise develops.
